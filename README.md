# trip-basket-new

Trip Basket 백엔드 서버 프로젝트입니다.

## Git hooks 설정

로컬에서 아래 명령어를 한 번 실행해 `.githooks`를 Git hooks 경로로 설정해주세요.

```bash
git config core.hooksPath .githooks
```
